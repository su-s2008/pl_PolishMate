## 🚀 Про проєкт

**pl_PolishMate** — це вебзастосунок для людей, які вивчають польську мову.

Проєкт допомагає вивчати польські слова, повторювати матеріал, перевіряти свої знання та поступово покращувати рівень польської мови.

Мета **pl_PolishMate** — створити простий, сучасний та корисний сервіс, яким можна користуватися щодня.
