# 🇵🇱 Про проєкт

**pl_PolishMate** — це сучасний вебзастосунок, створений для людей,
які хочуть **вивчати польську мову просто, швидко та регулярно**.

Проєкт поєднує словник, практичні завдання, пошук слів,
категорії та систему відстеження прогресу в одному зручному
інтерфейсі.

> 💡 **Мета:** перетворити вивчення польської мови на просту
> щоденну звичку.

# 🎯 Для кого?

**pl_PolishMate** підходить для:

- 🇺🇦 українців, які живуть у Польщі;
- 🎓 студентів та школярів;
- 🧑‍💻 людей, які починають вивчати польську;
- 🇵🇱 тих, хто хоче покращити словниковий запас;
- 💬 людей, які хочуть практикувати польську щодня.
